Quick Reference

Torque correction formulas

Setup 1

Standard

Tsetting = Trequired

Setup 2

Inline Adapter

T = T × L / (L + L1)

Setup 3

Adapter + Extension

T = T × L / (L + L1)

Setup 4

Rear Extension

T = T × (L + L2) / (L + L + L2)

Setup 5

Crowfoot 90°

Tsetting = Trequired

Setup 6

Offset Adapter

T = T × L / (L + L1)

Setup 7

Angled Adapter

T = T × L / (L + L3 × cos(180° − α))

Legend

Variables used in the formulas

Trequired

Required tightening torque

Tsetting

Torque wrench setting

L

Torque wrench length

L1

Inline or offset adapter length

L2

Rear extension length

L3

Angled adapter length

α

Adapter angle (degrees)

Notes

Important reminders

✔ Use the center of the square drive when measuring the wrench length (L).
✔ Measure all adapter lengths on the tool centerline.
✔ Use the same unit for every length (mm or in).
✔ The calculated value is the torque wrench setting.
✔ Always follow the Aircraft Maintenance Manual (AMM).
